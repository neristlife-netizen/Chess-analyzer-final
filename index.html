How to analyze a chess game

Load a PGN or FEN, or play a position directly on the board. The browser engine evaluates the current position and shows an engine score and best move.

What does the evaluation mean?

A positive number generally means the position favors White; a negative number favors Black. Larger absolute values indicate a bigger evaluation difference.

Improve from your games

Don't only look for the engine's best move. Compare your move with the position before and after it, then ask what changed: material, king safety, threats, or piece activity.

  • Check every tactical opportunity.
  • Look for repeated mistakes across games.
  • Review critical positions instead of every move equally.

PGN & FEN

PGN stores a game's moves and metadata. FEN describes a single chess position. You can paste either into the import box above.

FAQ

Is the analysis done in my browser?

Yes. This version loads the chess rules library and Stockfish JavaScript in the browser, so the core analysis does not require your own analysis server.

Does the site save my games?

The current version keeps the displayed user name and a small local game history in browser storage. It does not provide a server-side account system.
